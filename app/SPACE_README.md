# Retinal DR Screening

Diabetic retinopathy grading (0-4) with Grad-CAM explanations.
EfficientNet-B3 pretrained on EyePACS 2015, fine-tuned on APTOS 2019, externally
tested on IDRiD.

**Research demo, not a medical device.**

Source code: https://github.com/ashwinruke/retina-screen
