# Retinal DR Screening

Diabetic retinopathy grading (0-4) with Grad-CAM heatmaps. The model
(EfficientNet-B3, trained on APTOS 2019) runs in the visitor's browser with
ONNX Runtime Web, so photos are never uploaded.

**Research demo, not a medical device.**

Source code: https://github.com/ashwinruke/retina-screen
